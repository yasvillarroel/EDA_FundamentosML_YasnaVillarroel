# EV1-ML
Descripción del Proyecto
- Este proyecto tiene como objetivo explorar los factores que influyen en la rotación de empleados en una empresa. A partir de un dataset de Kaggle, realizamos un Análisis Exploratorio de Datos (EDA) para identificar patrones y posibles causas de la rotación de personal.

Estructura del Proyecto
- data/ → Contiene el dataset original en formato CSV.
- cnotebooks/ → Incluye los notebooks de Jupyter con el análisis paso a paso.
- README.md → Este archivo con detalles del proyecto.

Dataset
El dataset utilizado proviene de Kaggle e incluye información sobre empleados como:
- Edad
- Satisfacción laboral
- Salario diario
- Años en la empresa
- Nivel de educación
- Departamento
- Distancia al trabajo
- Rotación del empleado (Attrition)

Análisis Exploratorio de Datos (EDA)
- -El EDA incluyó las siguientes etapas:

- Identificación y descripción de variables (numéricas y categóricas).
- Medidas de tendencia central y dispersión (media, mediana, desviación estándar).
- Análisis de distribución (sesgo, simetría, histogramas y boxplots).

  Visualizaciones como:
  - Histogramas y gráficos de barras.
  - Diagramas de caja para comparar la edad y el salario con la rotación.
  - Tablas de frecuencia para categorías relevantes.

- Identificación de valores atípicos.
-Conclusiones preliminares sobre la rotación de empleados.

Principales Hallazgos
🔹 Edad vs. Rotación: Los empleados más jóvenes tienen mayor probabilidad de renunciar, mientras que los empleados de mayor edad tienden a quedarse en la empresa.
🔹 Salario Diario vs. Rotación: Aunque hay una gran variabilidad en los salarios, los empleados con ingresos más bajos parecen ser más propensos a abandonar la empresa.
🔹 Otros Factores: La satisfacción laboral y el equilibrio entre la vida y el trabajo podrían ser variables clave en la rotación, por lo que se recomienda analizarlas en profundidad.
